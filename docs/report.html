01 / CONSTRAINT ENCODINGS

Assignments decoded from actual SAT results

Graph coloring

Each vertex has exactly one color; adjacent vertices cannot share a color. The seven-cycle is satisfiable with three colors. A four-clique with three colors is unsatisfiable.

Latin square

One symbol per cell, with each symbol exactly once in each row and column. The first row is fixed to remove symbol-label symmetry. Every original CNF clause is verified.

02 / WATCHED LITERALS AND REFERENCE SCANNING

Propagation checks and measured solve time

Logarithmic axes. Reversed implication-chain ordering intentionally stresses repeated scanning. Check counts exclude satisfaction scans and other solver work. Unit order may change the search despite the shared decision heuristic.

Two watched literals

When a watched literal becomes false, inspect that clause, move the watch to a nonfalse literal, imply the remaining literal or report conflict. Watch positions survive backtracking.

Scanner reference

Repeatedly scan all clauses until no new unit implication remains. It shares preprocessing, the trail, decision order and result checks with the watched solver.

05 / VALIDATION AND REPRODUCTION

Bounded implementation and independent checks

Correctness evidence

1,800 random formulas up to eight variables are checked with an independent brute-force oracle against both propagation modes. Tests also cover watch movement, rollback, empty and unit clauses, tautologies, duplicate literals and malformed DIMACS.

python scripts/run_study.py --quick
python scripts/run_study.py --output-dir build/my-run
python scripts/verify_results.py --output-dir build/my-run

Limits

DPLL only: no clause learning, CDCL, restarts or proof logging. Maximum 256 variables, 5,000 input clauses and 50,000 input literals. Finite decision budgets return UNKNOWN.

Single-host instrumented timing; one untimed solve per fixture/mode. The study does not establish production performance or general benchmark rankings.
